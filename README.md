## 🌟 Features

- **8 Iconic Hypercars (Futuristic Concepts from Top Manufacturers)**:
  1. **Bugatti**: Bolide 2099 "Quantum" (W16 quad-plasma hybrid with central aerodynamic stabilizer)
  2. **Lamborghini**: Terzo Millennio "Cyber-V12" (Y-laser blade optics and razor carbon wedge)
  3. **Ferrari**: Vision Gran Turismo "Cyber-Rosso" (Flowing pontoon body with photonic taillight bar)
  4. **Porsche**: Mission X "Neo-Stuttgart" (Quad-matrix vertical headlights, Le Mans glass dome)
  5. **Tesla**: Cyber-Apex "SpaceX Hyperdrive" (Exoskeleton armor with dual cold-gas reaction thrusters)
  6. **McLaren**: Solus GT "Apex-2099" (Single-seat jet cockpit pod with biplane carbon wing)
  7. **Koenigsegg**: Jesko "Quantum-Absolut" (Visor canopy with dual fighter-jet vertical fins)
  8. **Aston Martin**: Valkyrie "AMR Pro 2099" (Full underside venturi ground-effect channels)

- **Cyberpunk Neo-Metropolis Circuit**:
  - Elevated multi-lane highway system with high-speed flyovers, loop curves, and neon barrier rails.
  - **Speed Boost Pads**: Glowing chevron pads that launch the car into hyper-speed and recharge nitro.
  - **Jump Ramps**: Launch hypercars into acrobatic mid-air jumps with suspension bounce physics.
  - 90+ illuminated skyscrapers, rooftop beacon towers, and animated 3D floating holographic billboards.

- **Dynamic Weather Modes**:
  - **Neon Night**: Classic cyberpunk neon glow and dark horizon.
  - **Cyber Rain**: Falling rain particles, slick road reflections, and mood lighting.
  - **Synth Sunset**: Warm synthwave purple/orange gradient atmosphere.

- **Arcade Driving Physics**:
  - Smooth acceleration curves with 7-speed transmission and virtual RPM calculation.
  - Oversteer drifting mechanics with live drift combo scoring and tire sparks.
  - Nitro boost with camera FOV hyperspace warp and speed line particles.

- **Zero-Dependency Web Audio Synthesis**:
  - Procedural engine revving, electric turbine spool, tire screech, and retro synthwave background arpeggiator.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run
```bash
# Clone the repository
git clone git@github.com:imran21-rgb/cyber-velocity.git
cd cyber-velocity

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack
- **Engine**: Three.js
- **Audio**: Web Audio API (OscillatorNode, BiquadFilterNode)
- **Bundler**: Vite
- **Styling**: Cyberpunk CSS with Orbitron & Rajdhani Typography
